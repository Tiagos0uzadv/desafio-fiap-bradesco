# Checklist de entrega

## Entregáveis do desafio

- [x] Protótipo funcional da aplicação web
- [x] Lógica de monitoramento e tomada de decisão
- [x] Arquitetura e diagramas da solução
- [x] Pelo menos 2 tipos de componentes/fontes de dados
- [x] 1 cenário completo: evento → decisão → ação
- [x] Níveis de autonomia e intervenção humana
- [x] Benefícios esperados para o negócio
- [x] Perfis de segurança e acesso
- [x] Integração com modelo de IA
- [ ] Slides da apresentação

## Antes de entregar

- [ ] `README.md` com os nomes dos três integrantes preenchidos
- [ ] Projeto roda do zero em outra máquina: clonar, `npm install`, `npm start`
- [ ] Nenhuma chave de API dentro do código (confira com `git log -p`)
- [ ] Todas as branches juntadas na principal
- [ ] Data de entrega confirmada com o professor

## Antes de apresentar

- [ ] Demo ensaiada 2 vezes, do início ao fim, com cronômetro
- [ ] Vídeo de reserva da demo gravado
- [ ] Servidor rodando e navegador aberto antes de entrar na sala
- [ ] Histórico limpo para a tela começar zerada
- [ ] Cada um sabe responder as perguntas da sua parte
- [ ] Combinado quem opera o computador durante a demo

## Perguntas para o professor

Confirmem antes de investir tempo:

- [ ] A integração com IA é obrigatória para a nota?
- [ ] O projeto vale nota em quais matérias?
- [ ] Quanto tempo temos de apresentação?
- [ ] Precisa entregar documentação escrita além do código?
