# Prompts do grupo

Cada pessoa abre o Claude (ou outra IA), cola o prompt da sua parte e já começa
sabendo o que existe, o que falta e o que precisa fazer. Ninguém começa do zero
nem reescreve o que já está pronto.

| Arquivo | Para quem |
| --- | --- |
| `prompt-pessoa-1-backend.txt` | Back-end: API, dados, execução, auditoria |
| `prompt-pessoa-2-logica-ia.txt` | Lógica e IA: regras e níveis de autonomia |
| `prompt-pessoa-3-frontend.txt` | Frontend e Negócio: painel, login, slides |

Quando o projeto mudar bastante, atualizem os prompts para refletirem o estado
novo. Um prompt desatualizado faz a IA sugerir coisas que já existem.
