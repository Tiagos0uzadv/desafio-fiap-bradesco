O QUE O DESAFIO PEDE
Um MVP web que monitora componentes de um ambiente, identifica situações de
risco ou comportamento fora do padrão e recomenda ou executa ações
automaticamente, com segurança, governança e intervenção humana quando
necessária. O objetivo não é automatizar tudo: é definir até onde o sistema
pode ir sozinho.

Requisitos: dashboard web; regras que definem a resposta; arquitetura modular
(monitoramento, análise, decisão, execução, identidade, auditoria); pelo menos
2 fontes de dados; perfis de acesso diferentes; ganhos de negócio; 1 cenário
completo evento -> decisão -> ação; registro de evento, decisão, quem autorizou
e resultado; integração com modelo de IA.

COMO O SISTEMA FUNCIONA HOJE
Duas fontes simuladas: aplicação web (taxa de erros) e API de pagamentos (tempo
de resposta). A cada 3 segundos o painel chama GET /status, o back-end gera uma
leitura e as regras decidem o nível de autonomia:
- 1 sinal acima do limite          -> alertar
- 1 sinal bem acima do limite      -> recomendar
- os 2 sinais juntos (degradação)  -> pedir aprovação (humano autoriza)
- falha conhecida de baixo risco   -> executar (ainda não implementado)
A IA escreve a recomendação em linguagem natural; se falhar ou não houver chave
de API, usa-se o texto das regras. Tudo gera registro de auditoria com evento,
decisão, quem autorizou e resultado.

PERFIS DE ACESSO
visualizador (só vê), operador (aprova ou rejeita ações) e admin (tudo, mais
simular falha). O frontend manda o perfil no cabeçalho x-perfil e o servidor
verifica em cada pedido, devolvendo 403 para quem não pode.
